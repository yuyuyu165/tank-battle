# 坦克大战 (Tank Battle)

一款使用原生 **HTML + Canvas + JavaScript** 编写的经典坦克大战游戏，单文件即可运行，零依赖、无需构建。

## 玩法

- 控制己方**黄色坦克**，消灭全部敌方坦克，并保护己方基地（老鹰图标）。
- 砖墙可被子弹摧毁，钢墙只能被强化后的子弹摧毁。
- 敌人会掉落各种道具，捡起即可获得加成。
- 共 3 个手工关卡，通关后进入随机生成的关卡，难度逐步提升。

## 操作

| 功能 | 按键 |
| ---- | ---- |
| 移动 | 方向键 / WASD |
| 开火 | 空格 / J |
| 暂停 | P 或 Esc |
| 静音 | M |
| 重新开始 | R |

移动端支持屏幕上的虚拟方向键与开火按钮。

## 道具

| 图标 | 效果 |
| ---- | ---- |
| ⭐ | 强化：子弹升级（可摧毁钢墙、双发） |
| 🛡️ | 护盾：短暂无敌 |
| ❤️ | 生命：增加一条命 |
| 💣 | 炸弹：消灭屏幕上所有敌人 |
| ⏰ | 冻结：冻结敌人移动 |

## 运行

直接用浏览器打开 `index.html` 即可开始游戏。

也可以部署到 GitHub Pages：

1. 仓库 **Settings → Pages**
2. **Deploy from branch**
3. 选择 `main` 分支，根目录 `/ (root)`
4. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 在线游玩
